# Campagna VAS 10 - parallelismo ibrido MPI + CUDA su una singola GPU.
#
# Il problema globale resta M=N=16384 in FP64. Il livello MPI divide il
# problema su una griglia di processi; ogni rank esegue poi il proprio prodotto
# locale con il backend CUDA selezionato. Le griglie sono bilanciate:
#   P=1 -> 1x1, P=2 -> 2x1, P=4 -> 2x2, P=8 -> 4x2.
#
# a_mode=global e x_mode=global fanno generare gli input globali sul root e ne
# misurano separatamente la distribuzione iniziale. P=1 e' soltanto la baseline
# interna per speedup ed efficienza; i casi ibridi richiesti sono P=2,4,8.
#
# Il nodo ha una sola GPU e tutti i rank usano il device 0 senza MPS: i dati
# descrivono quindi il costo della soluzione ibrida e la contesa fra contesti,
# non lo scaling multi-GPU.
#
# Esecuzione:
#   ./script/run_cuda_experiments.sh --suite experiments/fase_5_mpi_cuda/campagna_VAS_10_mpi_cuda_hybrid.txt
